- `sample` 数据源用于离线演示和确定性测试，不表示实时行情。
- 真实 Profile、账户、持仓和交易数据只应保存在本机应用数据目录或用户指定的外部数据目录，不提交到仓库。
- 公开截图不能作为投资建议、收益预测或实际交易依据。
