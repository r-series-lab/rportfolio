# rPortfolio 界面与公开演示说明

rPortfolio 是本地优先的组合决策工作台。公开界面素材只展示应用内置示例数据模式和仓库内置演示 Profile，不包含真实账户、持仓、订单或收益历史。截图统一使用暗色主题。

主界面由五个菜单工作区组成，外加一个从持仓或决策进入的资产研究视图。

## 今日 — 行动、阻断与复核

![今日工作区](assets/workspace-today-dark.png)

每天打开应用的起点：概况瓦片汇总待处理、阻断、延期和已闭环数量；行动队列按优先级展示当前仓位、目标区间、计划金额与证据状态；右侧检查器提供决策理由、风险检查和拒绝、已复核、延期、接受并执行四个动作。

## 组合账户 — 账户、现金、持仓与对账

![组合账户 · 账户](assets/workspace-holdings-accounts-dark.png)

账户标签维护人民币 / 美元现金口径：可用现金、已结算、待交收和账户权益，加上账户清单。现金是仓位规划和下单预算的事实来源。

![组合账户 · 持仓](assets/workspace-holdings-dark.png)

持仓标签是本地资产台账：搜索与范围筛选、市值 / 目标带 / 盈亏 / 建议列，右侧检查器展示目标带滑块、阻断原因和资产资料来源；摘要卡按健康度着色。

## 组合决策 — 状态、证据与仓位

![组合决策工作区](assets/workspace-analysis-dark.png)

Profile 分析的主展示页面：概览、结构、回测、规则、指标五个证据标签，决策 / 检查两种视角，右侧风险栏展示系统 / 结构 / 过热 / 波动四个风险维度与状态转移估计。

## 量化交易 — 监测、下单、执行

![量化交易工作区](assets/workspace-quant-dark.png)

把组合建议转化为可回放的执行账本：环境摘要、按优先级排序的可建票建议、右侧委托执行栏（交易票、委托、账户、模拟、日志）与纸面成交支持；风险门异常时进入只减不加等保护模式。

## 复盘归因 — 收益、结果与晋级

![复盘归因工作区](assets/workspace-review-dark.png)

维护日终估值与业绩账本：日结准备度六项检查（全部对齐才允许记录正式快照）、TWR / MWR / 净超额等收益指标、归因拆解、估值时间轴与版本晋级队列。

## 公开截图规则

- 截图使用应用内置示例数据模式与内置演示 Profile，不包含真实账户、个人持仓、订单或收益历史。
- 演示模式阻断真实下单；只减不加等保护门保持开启。
